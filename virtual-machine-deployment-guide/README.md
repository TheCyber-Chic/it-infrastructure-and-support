<h3>Virtual Machine Deployment Guide</h3>
<p>A technical operations guide that establishes repeatable procedures for deploying, configuring, and managing virtual machines using Oracle VM VirtualBox.

## <h3>Environment and Tools</h3>
- Oracle VM VirtualBox
- Windows Server 2019 Standard Evaluation (Desktop Experience)
- Windows 11 Pro
- Kali Linux 2026.2

## <h3>What the Guide Covers</h3>
- Host system preparation and virtualization requirements
- Role-based virtual network configuration
- Virtual machine naming conventions
- Operating system deployment and configuration
- Snapshot creation, restoration, and cleanup
- Post-installation configuration and verification
