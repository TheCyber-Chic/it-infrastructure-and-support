<h3>Active Directory Lab</h3>
<p>An independent virtualised Windows domain environment built in Oracle VM VirtualBox to practise Windows Server administration, identity and access management, network services, and troubleshooting.</p>

## <h3>Environment</h3>
- Oracle VM VirtualBox
- Windows Server 2019 Standard (Desktop Experience)
- Windows 11 Pro

## <h3>What I Implemented</h3>
- Configured Windows Server as a domain controller with Active Directory Domain Services (AD DS).
-Configured DNS and DHCP.
-Set up Routing and Remote Access Services (RRAS) with Network Address Translation (NAT).
-Created organisational units and test user accounts.
-Joined a Windows 11 Pro client to the domain.

## <h3>Troubleshooting</h3>
Investigated and resolved issues involving DNS SRV record lookups, VirtualBox network adapter configuration, Windows edition compatibility, and password policy constraints.

## <h3>Validation</h3>
- Successfully joined the Windows 11 client to the domain
- Verified domain user login and DNS name resolution
- Confirmed internet connectivity from the domain client
- Verified the client appeared in Active Directory Users and Computers
